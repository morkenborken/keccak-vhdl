# keccak-vhdl
A VHDL implementation of Keccak and some derived functions, including SHA3-(224, 256, 384, 512) and SHAKE(128, 256).

# Dependencies
* [GHDL](http://ghdl.free.fr/)
* [cocotb](https://pypi.org/project/cocotb/)
* [cocotbext-axi](https://pypi.org/project/cocotbext-axi/)
* [pycryptodome](https://pypi.org/project/pycryptodome/)
